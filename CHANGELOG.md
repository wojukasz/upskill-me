## [0.1.0] - 2026-11-19

### Added

- `coach-me`: hints and questions while you do the work yourself, in nine
  modes (mechanism, build, practice, troubleshoot, read, review, design,
  recall, explain).
- `tutor-me`: the real answer, packaged to teach: what good looks like, how it
  works, commands for you to run, and how to find it yourself next time.
- `explain-change-me`: the mechanism, settings, blast radius and rollback of a
  change, before it is made.
- Optional learner profile at `~/.config/upskill-me/profile.md`, read by all
  three skills; an example is in `examples/profile.md`.
- Claude Code plugin and marketplace manifests.
